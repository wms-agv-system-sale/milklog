# 奶量日记（安卓版）

把奶瓶放进画面，自动读出当前奶量，并做日 / 周 / 月统计折线图，用来看宝宝奶量的变化。

- 不联网、不注册、不上传。所有数据只存在手机本地。
- 识别结果可以按实际情况改数值。
- 识别原理是「液面高度 ↔ 毫升数」，所以要先做一次标定（见下）。

> 换安卓这件事其实是好消息：**不需要签名、不需要 7 天续期、不需要 Mac、不需要 Sideloadly**。装一次就能长期用，不会过期。

---

## 一、怎么装到安卓手机上

### 方式 A：云端自动打包（不用电脑装开发工具，推荐）

1. 把这个文件夹里的**全部内容**上传到你的 GitHub 仓库（`android` 文件夹和 `.github` 文件夹都要）。
2. 上传后 GitHub 会自动开始编译。打开仓库的 **Actions** 页面，能看到一次叫「构建安卓安装包」的运行。
3. 等它变成绿色对勾（约 3~5 分钟），点进这次运行，在页面**最下方**的 **Artifacts** 里下载 `MilkLog-Android-APK`。
4. 下载下来是一个 zip，解压得到 **`app-debug.apk`**，这就是安装包。
5. 把 `app-debug.apk` 发到手机上（微信「文件传输助手」、数据线、网盘都可以）。
6. 在手机上点开这个文件安装。系统提示「为了安全，你的手机不允许安装未知来源的应用」时，按提示点**设置 → 允许来自此来源的应用 → 返回 → 安装**。
7. 桌面出现「奶量日记」图标，装好了。

> 小提示：用微信打开 apk 时，如果提示不能直接安装，点右上角「…」→「用其他应用打开」→ 选「文件管理」或「浏览器」再装。

### 方式 B：用 Android Studio 直接运行（电脑上装 Android Studio）

1. 电脑上安装 **Android Studio**（免费）。
2. Android Studio 里选 `Open`，指向本文件夹里的 **`android`** 目录。
3. 等它自动下载依赖（第一次会花几分钟）。
4. 手机用数据线连电脑，手机里打开「开发者选项 → USB 调试」。
5. 顶部选到你的手机，点绿色的运行按钮，App 会自动装到手机上。

## 二、使用步骤

### 1. 标定奶瓶（只做一次，2 分钟）

1. 打开 App，点「开始标定」。
2. 把手机固定在一个位置（用支架最稳），让奶瓶出现在虚线框里。
3. 给奶瓶倒入一个已知奶量（比如用量杯量 120ml），点「识别并记录」。
4. 换一个奶量（比如 60ml），再记录一次。至少 **2 个点**，3 个点更准。
5. 自动识别不到液面时，点「点选液面」，直接在画面上点液面的位置。
6. 点「完成」。

### 2. 日常记录

- 打开 App，把奶瓶放到**同一个位置**，画面里会出现一条虚线标出液面，下方的大数字就是奶量。
- 读数稳定后点「保存记录」，还可以在弹窗里按实际奶量微调。
- 没有支架时，也可以点「手动输入」直接记。

### 3. 看统计

- 「统计」页可以切换 **日 / 周 / 月**，折线图看奶量变化。
- 日视图里的橙色虚线是「每日目标」，可以在设置里改。
- 点任意一条记录可以改数值、改时间、加备注或删除。

### 4. 其他

- 支持多个奶瓶：在「设置 → 奶瓶与标定」里添加，各自标定一次，用的时候切换「当前」奶瓶。
- 「设置 → 导出全部记录」可以把数据发到微信或邮箱备份一份。

## 三、常见问题

**数据存在哪里？**
只存在这台手机的 App 私有目录里。卸载 App 会一起删掉，重要数据建议偶尔导出备份。

**会过期吗？**
安卓不会。装一次就一直是你的（不像 iPhone 免费账号那样 7 天要重装一次）。

**要多新的安卓手机？**
安卓 8.0 及以上都可以（大约 2017 年以后的手机）。

**识别不准怎么办？**
1) 手机固定住，奶瓶每次放同一个位置；2) 光线均匀，别逆光；3) 把标定里的「取样区域」虚线框收窄到刚好罩住瓶身；4) 数值不合适时保存前直接改。
