# 奶量日记（MilkLog）

一个完全离线的 iPhone App：**把奶瓶放进画面，自动读出当前奶量**，并做日 / 周 / 月统计折线图，用来看宝宝奶量的变化。

- 不联网、不注册、不上传。所有数据只存在手机本地。
- 拍照识别 + 手动修改：识别结果可以按实际情况改数值。
- 识别的原理是「液面高度 ↔ 毫升数」，所以需要先做一次标定（见下）。

---

## 一、怎么装到 iPhone 上

### 方式 A：有 Mac（最简单）

1. Mac 上安装 **Xcode 16 或更新版本**（App Store 免费）。
2. 双击打开 `MilkLog.xcodeproj`。
3. Xcode 菜单 `Xcode → Settings → Accounts`，用你的 Apple ID 登录（免费账号即可）。
4. 左侧选中项目 → `Signing & Capabilities` → 勾选 `Automatically manage signing` → `Team` 选你自己的账号。
   - 如果提示 Bundle Identifier 冲突，把 `com.example.milklog` 改成任意独一无二的名字，例如 `com.你的名字.milklog`。
5. 用数据线连接 iPhone，顶部设备选择你的手机，点 ▶️ 运行。
6. 第一次运行后，iPhone 上要到 **设置 → 通用 → VPN与设备管理**，信任你的开发者证书；
   再到 **设置 → 隐私与安全性 → 开发者模式** 打开开发者模式并重启手机。
7. 免费 Apple ID 的签名 **7 天过期**，到期后重新用 Xcode 运行一次即可（数据不会丢）。付费开发者账号（$99/年）可以维持 1 年。

### 方式 B：没有 Mac

用 GitHub Actions 免费提供的 macOS 机器帮你编译，再在 Windows 上用 Sideloadly 装进手机：

1. 注册 GitHub 账号，新建一个仓库（可以设为 Private）。
2. 把本文件夹（`MilkLog`）里的**全部内容**作为仓库根目录上传。仓库里已经带好了 `.github/workflows/build-ipa.yml`。
3. 上传后 GitHub 会自动开始编译（也可在 Actions 页面点 `Run workflow`）。约 3~5 分钟后，在该次运行的 **Artifacts** 里下载 `MilkLog.ipa`。
4. Windows 上安装 [Sideloadly](https://sideloadly.io/) 和 iTunes（或微软商店的「Apple 设备」App）。
5. 手机连接电脑，把 `MilkLog.ipa` 拖进 Sideloadly，输入你的 Apple ID，点 Start。
6. 手机上的信任步骤同方式 A 的第 6 步。
7. 免费 Apple ID 同样 7 天过期，用 Sideloadly 重新安装一次即可（**不要先删除 App**，直接覆盖安装数据不会丢）。

> 建议：偶尔用 App 里「设置 → 导出全部记录」备份一份数据。

## 二、使用步骤

### 1. 标定奶瓶（只做一次，2 分钟）

1. 打开 App，点「开始标定」。
2. 把手机固定在一个位置（用支架最稳），让奶瓶出现在虚线框里。
3. 给奶瓶倒入一个已知奶量（比如用厨房秤量 120ml），点「识别并记录」。
4. 换一个奶量（比如 60ml），再记录一次。至少记录 **2 个点**，3 个点更准。
5. 如果自动识别不到液面，点「点选液面」，直接在画面上点液面的位置即可。
6. 点「完成」。

### 2. 日常记录

- 打开 App，把奶瓶放到**同一个位置**，画面里会出现一条黄线标出液面，下方的大数字就是奶量。
- 读数稳定（变绿）后点「保存记录」，还可以在弹窗里按实际奶量微调。
- 没带手机支架？也可以点「手动输入」直接记。

### 3. 看统计

- 「统计」页里切换 **日 / 周 / 月**，折线图分别显示最近 14 天 / 8 周 / 6 个月的奶量变化，下面还有每天明细，点进去可以修改或删除。

## 三、想更准，注意这几点

- **手机位置尽量固定**：这是「拍照测体积」的物理限制。支架 / 固定放在同一个桌面角落都可以。
- 背景尽量简单（纯色墙面最好），避免强反光；光线不够可以开 App 里的闪光灯补光。
- 奶瓶放正、别倾斜。
- 如果总是识别不准：进标定页，把「取样区域」左右两条边界收窄到刚好罩住瓶身。
- 数值不对时，保存前直接改就行。

## 四、常见问题

| 问题 | 答案 |
| --- | --- |
| 需要联网吗？ | 不需要。识别、统计全部在手机上完成，App 里没有任何联网代码。 |
| 可以多个奶瓶吗？ | 可以。设置里给每个奶瓶分别标定，用时切换当前奶瓶。 |
| 显示 `--` 或 0？ | 没找到液面。检查奶瓶是否在虚线框内、光线是否够、奶量是否低于标定范围。 |
| 换手机后数据？ | 数据在本机。先「导出全部记录」，换机后数据不会自动同步（本 App 不联网）。 |
| 苹果认证过期了？ | 免费 Apple ID 是 7 天，重新运行一次 Xcode / Sideloadly 覆盖安装即可。 |
